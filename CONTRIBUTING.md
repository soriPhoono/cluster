# Contributing

## Issues

1. Open an issue describing the bug, feature, or task
1. Use a descriptive title and clear steps to reproduce (if applicable)

## Branch Naming

Use the following format:

- `fix/<issue-number>-<short-description>`
- `feat/<issue-number>-<short-description>`

Example: `fix/123-update-k8s-flux-config`

## Workflow

1. Create a branch from `main`
1. Make your changes
1. Push and open a pull request against `main`
1. Request review before merging

## Rules

- **Never commit directly to `main`** - all changes come through PRs
- Keep PRs focused and atomic
- Ensure pre-commit hooks pass before requesting review
